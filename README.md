# Cab-Link

Where Brooklyn bus delays send riders next — an interactive map of 55
Brooklyn bus routes, a delay-alert layer backtested on 2024 MTA data, and a
synthetic cab fleet with precomputed drive times.

**Live demo:** https://sbracco2003.github.io/cab-link-demo/

This is a single self-contained static page (`index.html`) pulled from a
larger capstone project — no backend, no build step. Open it directly in a
browser, or visit the live link above.
